কৃষি সংযোগ

কৃষক, ক্রেতা ও সংগ্রহ কেন্দ্রকে একসাথে যুক্ত করে স্থানীয় কৃষি কার্যক্রম সহজে পরিচালনার বাংলা প্ল্যাটফর্ম।

অ্যাপ চালু করুন

ইন্টারঅ্যাকটিভ মোবাইল ও ওয়েব অ্যাপ চালাতে repository root থেকে npm run dev:web চালান। Expo যে local URL দেখাবে, সেটি browser-এ খুলুন।

API ও ডাটাবেস সেটআপের জন্য প্রকল্পের README-তে থাকা local setup নির্দেশনা অনুসরণ করুন।
